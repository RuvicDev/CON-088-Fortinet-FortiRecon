1. ¿Qué es y para qué sirve?

FortiRecon ayuda a gestionar la superficie de ataque externa, identificando activos expuestos, riesgos, filtraciones de credenciales y hallazgos de seguridad.

security.get_exposed_assetsConsulta activos o servicios expuestos.
security.get_risksConsulta riesgos de exposición.
security.get_compromised_credentialsConsulta credenciales comprometidas.
security.get_findingsConsulta hallazgos/issues ASM.

2. Prerrequisitos

  • Tenant FortiRecon con API habilitada.
  • API Key de solo lectura.
  • Organization ID.
  • URL base HTTPS de la API.

3. Configuración en FortiRecon

  1. Solicita o genera una API Key.
  2. Confirma el Organization ID.
  3. Valida los endpoints/path templates disponibles para tu versión.
    [ Captura: API Key y organización FortiRecon — reemplazar si aplica ]

4. Permisos requeridos

La API Key debe tener permisos de lectura sobre ASM/EASM, activos expuestos, issues/hallazgos y credenciales filtradas.

5. Configuración en Ruvic

Completa URL base, API Key, Organization ID, verificación SSL y path templates si tu tenant usa rutas distintas.

6. Verificación

Ejecuta Probar conexión y luego consulta hallazgos, activos, riesgos y credenciales.

7. Solución de problemas

401/403API Key, organización o permisos inválidos.
404Path template o endpoint no disponible en el tenant.
SSLCertificado no confiable; revisa VERIFY_SSL.

8. FAQ y seguridad

No compartas API Keys. Trata credenciales comprometidas como información sensible y usa claves de mínimo privilegio.
